agent-room 개인정보처리방침

시행일: 2026년 10월 11일

1. 누가 쓰는 앱인가요

agent-room은 운영자 한 사람이 자기 PC에서 돌리는 개인용 앱입니다. 운영자 본인의 구글 계정만 연결하며, 다른 사람의 계정이나 데이터를 받지 않습니다.

2. 구글에서 읽는 정보

  • 구글 캘린더: 운영자가 고른 캘린더의 일정 제목, 시작·끝 시각, 장소, 종일 여부, 캘린더 이름. 일정 설명·참석자·회의 링크는 구글에 요청하지 않습니다.
  • 캘린더 쓰기: 이 앱이 만든 '아스카 기록' 캘린더에만, 운영자가 화면에서 [캘린더에 추가]를 누를 때만 일정을 넣습니다. 참석자 초대는 하지 않습니다.

3. 어디서 처리하나요

  • 모든 처리는 운영자의 PC에서 돌아가는 서버에서 합니다. 이 앱을 위한 별도의 클라우드 서버는 없습니다.
  • 구글 연결 정보(갱신 토큰)는 운영자 PC의 사용자 환경변수에만 둡니다.

4. 누구에게 보내나요

  • 운영자가 일정에 관해 물으면, 답을 만들기 위해 읽은 일정 정보를 AI API 제공사(Anthropic, OpenAI)에 보냅니다. 운영자가 요청한 답을 만드는 데만 씁니다.
  • 운영자 휴대폰으로 보내는 알림에 비서 답의 첫 줄이 들어갈 수 있습니다. 알림 내용은 암호화되어 운영자가 등록한 기기로만 갑니다.
  • 구글 데이터를 팔거나, 광고에 쓰거나, 위 목적 밖의 제3자에게 넘기지 않습니다.
  • 구글 데이터를 AI 모델 학습에 쓰지 않고, 학습용으로 제공하지 않습니다.

5. 얼마나 보관하나요

  • 읽은 일정 원본은 저장하지 않습니다. 비서의 답에 들어간 내용만 운영자 PC의 대화 기록에 남습니다.
  • 운영자가 추가를 요청한 일정안(제목·시각·장소·메모)은 처리 상태와 함께 운영자 PC에 기록합니다.
  • 대화 기록과 그 백업은 운영자 PC와 운영자 본인의 구글 드라이브에만 두며, 운영자가 직접 관리합니다.

6. 연결 끊기

구글 계정의 서드 파티 앱 접근 권한 화면에서 agent-room의 접근을 언제든지 삭제할 수 있습니다. 삭제하면 이 앱은 더 이상 구글 데이터를 읽거나 쓰지 못합니다.

7. 구글 API 사용자 데이터 정책

agent-room이 구글 API에서 받은 정보를 쓰고 다른 앱으로 보내는 일은 구글 API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

agent-room's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. 바뀌는 경우

읽는 정보가 늘거나 처리 방식이 바뀌면 이 페이지를 먼저 고치고 시행일을 바꿉니다.
